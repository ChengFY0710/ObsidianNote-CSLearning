## 前缀和
前缀和的思想是重复利用计算过的子数组之和，从而降低区间查询需要累加计算的次数。
**前缀和 在涉及计算区间和的问题时非常有用**！
![[引用文件/Algorithm-Learning/2-06-1.png]]
所以要计算2-5区间内的和，只需计算 p[5] - p[1] 即可。
C++ 代码 面对大量数据 读取 输出操作，最好用scanf 和 printf，耗时会小很多：
```cpp
#include <iostream>
#include <vector>
using namespace std;
int main() {
    int n, a, b;
    cin >> n;
    vector<int> vec(n);
    vector<int> p(n);
    int presum = 0;
    for (int i = 0; i < n; i++) {
        scanf("%d", &vec[i]);
        presum += vec[i];
        p[i] = presum;
    }

    while (~scanf("%d%d", &a, &b)) {
        int sum;
        if (a == 0) sum = p[b];
        else sum = p[b] - p[a - 1];
        printf("%d\n", sum);
    }
}
```
