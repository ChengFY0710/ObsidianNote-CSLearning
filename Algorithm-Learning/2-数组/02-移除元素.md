给你一个数组 nums 和一个值 val，你需要 原地 移除所有数值等于 val 的元素，并返回移除后数组的新长度。

不要使用额外的数组空间，你必须仅使用 O(1) 额外空间并**原地**修改输入数组。

元素的顺序可以改变。你不需要考虑数组中超出新长度后面的元素。

示例 1: 给定 nums = [3,2,2,3], val = 3, 函数应该返回新的长度 2, 并且 nums 中的前两个元素均为 2。 你不需要考虑数组中超出新长度后面的元素。

示例 2: 给定 nums = [0,1,2,2,3,0,4,2], val = 2, 函数应该返回新的长度 5, 并且 nums 中的前五个元素为 0, 1, 3, 0, 4。

**你不需要考虑数组中超出新长度后面的元素**

## （1）暴力解法
两层for循环，一个for循环遍历数组元素 ，第二个for循环更新数组。

![[引用文件/Algorithm-Learning/2-02-1.gif]]

```cpp
class Solution {
public:
    int removeElement(vector<int>& nums, int val) {
        int lenth = nums.size();
        for(int i=0; i<lenth; i++){
            if(nums[i] == val){
                for(int j = i+1; j<lenth; j++){
                    nums[j-1] = nums[j];
                }
                i--;
                lenth--;
            }
        }
        return lenth;
    }
};
```

## （2）双指针法
通过**一个快指针和慢指针**在**一个for循环下**完成两个for循环的工作。
定义快慢指针：
+ **快指针**：寻找新数组的元素，新数组就是不含有目标元素的数组。
+ **慢指针**：指向更新新数组下标的位置。

![[引用文件/Algorithm-Learning/2-02-2.gif]]
```cpp
// 时间复杂度：O(n)
// 空间复杂度：O(1)
class Solution {
public:
    int removeElement(vector<int>& nums, int val) {
        int slowIndex = 0;
        for (int fastIndex = 0; fastIndex < nums.size(); fastIndex++) {
            if (val != nums[fastIndex]) {
                nums[slowIndex++] = nums[fastIndex];
            }
        }
        return slowIndex;
    }
};
```

快指针指向的是新数组所需要的值，慢指针指向的是新数组。**当找到新数组需要的值后（满足条件 val != nums[fastIndex]），将快指针指向的值赋值给慢指针**，此后，慢指针后移，最后慢指针的**下标**就是**数组长度**。
