## 01 数组
本题实际上在判断一个字符串的字符是否出现在另一个字符串里，那么可以利用哈希表。
**数组**其实就是一张哈希表，由于本题只涉及 26 个小写字母，那么可以建立一张长度为26的哈希表。
![[引用文件/Algorithm-Learning/4-02-1.gif|402]]建立一个 record 的数组，用来记录s中的字母出现多少次，再遍历t，出现的字符在record上**减1**，这样**record里如果有不为0的元素，那么这两个字符串就不是字母异位词**。
```cpp
class Solution {
public:
    bool isAnagram(string s, string t) {
        int letter[26]={0};
        for(auto it = s.begin(); it != s.end(); it++){
            letter[*it-'a']+=1;
        }
        for(auto it = t.begin(); it != t.end(); it++){
            letter[*it-'a']-=1;
        }
        for(int i=0; i<26; i++){
            if(letter[i] != 0)
                return false;
        }
        return true;
    }
};
```
