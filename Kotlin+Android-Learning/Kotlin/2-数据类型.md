## 01 声明特定数据类型的变量
```kotlin
var a:Boolean = true  
var b:Char = 'R'  
var c:Byte = 12  
var d:Short = -356  
var e:Int = 43543  
var f:Long = -432543234L  
var g:Float = 5.666F  
var h:Double = 7.345
```

>[!warning]
>类型名首字母要**大写**！！！而且要**完整**！！

## 02 数据类型的转换
```kotlin
fun main(args: Array<String>) {  
    var a:Byte = 127  
    var b:Short = a.toShort()  
    var c:Int = b.toInt()  
    var d: Float = c.toFloat()  
    var e: Double = d.toDouble()  
  
    println(e)  
}
```

>[!warning]
>大数据类型转换为小数据类型可能会发生数据丢失。
