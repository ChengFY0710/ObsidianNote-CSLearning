
| Method                 | Description                      |
| ---------------------- | -------------------------------- |
| length()               | 返回字符串长度                          |
| equals(Object another) | 比较两个字符串，若两个字符串相同返回true，否则返回false |
| isEmpty()              | 若字符串长度为 0 返回 true，否则返回 false     |
| plus("...")            | 返回连接好的两个字符串                      |
| lowercase()            | 返回一个小写的字符串                       |
| uppercase()            | 返回一个大写的字符串                       |
| trim()                 | 返回移除单词开头和结尾处的空格                  |
