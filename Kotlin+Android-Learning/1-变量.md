## 01 可变量与不可变量
```kotlin
var speed = 100;
val speed = 100;
```
+ **可变量（Mutable variable）**：var
+ **不可变量（Immutable value）**：val

Basically, both val and var are used to declare a variable, but var is like a general variable, and **can be assigned mutiple times**. Whereas val is a **constant variable** and **cannot be assigned mutiple times** and **can be initialized only one single time**.
