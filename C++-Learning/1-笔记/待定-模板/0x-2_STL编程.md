# 0x-2_STL编程

## 00 概述
除了从 C 标准库保留下来的一些功能外，C++ 标准库还提供了很多新的功能，这些功 能大都以**函数模板和类模板**的形式出现，它们构成了 **C++ 的标准模板库**（Standard Template Library，STL）。

STL 主要包含一些**容器类模板**、**算法函数模板**以及**迭代器类模板**。

## 01 容器
容器（container）是**长度可变的****同类型元素**所构成的**序列**。
容器由**类模板**实现，模板的**参数**是容器中**元素的类型**。
