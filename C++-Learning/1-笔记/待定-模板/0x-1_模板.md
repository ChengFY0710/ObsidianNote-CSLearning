# 0x-1_模板
模板(template)是一段程序代码，它带有类型参数，在程序中可以通过给这些参数提供一些类型来得到针对不同类型的具体代码。

## 01 函数模板
```cpp
template <class T1, class T2, ...>
<返回值类型><函数名>(<参数表>){
    ...
}
```

>[!warning]
>关键词class也可以写成typename

实例：
```cpp
template <class T>
void sort(T elements[], int num){
    T temp=elements[i];
    elements[i]=elements[j]; 
    elements[j]=temp;
}

template <class T>
T max(T a, T b){
    return a>b?a:b;
}
```

### 函数模板实例化
实际上，函数模板定义了一系列**重载的函数**，要使用函数模板所定义的函数（称为模板函数），首先必须要对函数模板进行**实例化**（生成具体的函数，instantiation）。

函数模板的实例化通常是**隐式**的，即编译程序会根据调用时实参的类型**自动把函数模板实例化为具体的函数**。

然而，编译程序有时无法根据调用时的实参类型来确定所调用的模板函数，这时需要**显式实例化**。

```cpp
template <class T>
T max(T a, T b){
    return a>b?a:b;
}

int x, y;
double m,n;
max<double>(x,m);
// or
max((double)x, m);
```

除了类型参数外，模板也可以自带**非类型参数**。
```cpp
template <class T, int size>
void f(T a){
    T temp[size];
}

f<int, 10>(1);
```

## 02 类模板
如果一个类定义中用到的**类型可变**但操作不变，该类称为类属类。
```cpp
template <class T1, class T2, ...>
class <类名>{
    ...
}
```
如果类中函数的实现在外部，则需要这样写：
```cpp
template <class T1, class T2, ...>
<返回值类型> <类名><T1, T2, ...>::<成员函数名>(<参数表>){
    ...
}
```

实例：
```cpp
template <class T>
class student{
    T number;
public:
    T enlarge();
};

template <class T>
T student<T>:: enlarge(){
    number++;
    return number;
}
```

### 类模板实例化
>[!warning]
>类模板的实例化需要在程序中**显式地指出**

```cpp
student<int> st1;
student<double> st2;
```

>[!warning]
>类模板中的静态成员**仅属于实例化后的类**，不同实例之间**不共享**类模板中的静态成员。

## 03 模板的复用问题
>[!warning]
>为避免链接问题，模板通常**必须把定义全部写在头文件里**。
