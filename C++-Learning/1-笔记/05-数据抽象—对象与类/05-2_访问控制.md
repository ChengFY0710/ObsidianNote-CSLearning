# 05-2_访问控制

在C++类定义中，可以用成员访问控制修饰符``public``, ``private``, ``protected``来描述对类成员的访问限制。

## 01 public
成员的访问**不受限制**，在程序中的**任何地方**都可以访问一个类的public成员。

## 02 private
成员只能在**本类和友元**中访问。

>[!warning]
>C++类成员的默认访问控制是private（结构struct、联合union中默认为public）。

## 03 protected
成员只能在**本类、友元和派生类**中访问。

```cpp
class A {
    int m, n;
public:
    int x;
    void f();
private:
    int y;
    void g();
protected:
    int z;
    void h();
public:
    void f1();
}
```

---

对类成员的访问除了要受到成员访问控制修饰符的限制以外，**还要受到标识符作用域的限制**。

类定义构成一个作用域——**类作用域**。在类外部使用类中定义的标识符时，需通过**对象名受限**或**类名受限**。

>[!warning]
>在类中使用与成员标识符同名的全局标识符时，需要在全局标识符前面加上**全局域解析符::**。

---

## 需注意
```cpp
class A{
public:
    void f(){
        A a;
    }
private:
    int x;
    void g(){
        ...
    }
protected:
    int y;
    void h(){
        ...
    }
};
void func(){
    A a;      
    a.f();      // OK
    a.x = 1;    // Error
    a.y = 1;    // Error
    a.g();      // Error
    a.h();      // Error
}
```
在上面程序中，对于在 A 类的成员函数 f 中创建的 A 类对象 a，由于是**在 A 类的成员函数中对它进行访问**，因此不受 A 类的成员访问控制的限制，可以访问它的所有成员。

>[!warning]
>访问控制是针对**类外的**，类内不受限。
