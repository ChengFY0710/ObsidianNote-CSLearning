# 05-1_类

## 01 类的定义
在C++中，类的定义格式如下：
```cpp
class Student{
    成员描述
};
```
举例：
```cpp
class Date{
public:
    void set(int y, int m, int d);
    bool is_leap_year();
    void print();
private:
    int year,month,day;
};
```

## 02 数据成员
数据成员是指类的对象所包含数据，他们可以是**常量和变量**。在类的定义中需要对数据成员的**名字和类型**进行说明，其格式与结构成员的说明格式相同。

>[!warning]
>数据成员的类型可以是任意的C++类型（包括类，但**void除外**），但是，在声明一个成员的类型时，如果**未见到**相应的类型定义或相应的类型**未定义完**，则该数据成员的类型一般只能是这些类型的**指针或引用类型**。

```cpp
class A;
class B {
    A a;        // Error，未见A的定义，其所需内存空间大小未知
    B b;        // Error，B未定义完
    A *p;       // OK
    B *q;       // OK
    A &aa;      // OK
    B &bb;      // OK
};
```
>[!warning]
>在类的定义中描述数据成员时**一般不能给它们赋初值**，数据成员的初始化应该在**类的构造函数**中指出。

## 03 成员函数
成员函数是指在类中定义的函数，它描述了对类中定义的数据成员所能实施的操作。

在类中定义成员函数时，成员函数的实现可以放在类的定义中，也可以放在类的定义外。
### （1）在类定义中给出成员函数的实现
```cpp
class Date{
public:
    void set(int y, int m, int d){
        year = y;
        month = m;
        day = d;
    }
    bool is_leap_year(){
        return (year%4 == 0 && year%100 != 0) || (year %400 == 0);
    }
    void print(){
        cout << year << month << day << endl;
    }
private:
    int year, month ,day;
}
```
>[!tip]
>当把成员函数的实现放在类的定义中时，编译程序将按**内联函数**来处理它们。
### （2）在类定义外给出成员函数的实现
在类定义外实现成员函数，首先应该**在类内给出成员函数的声明**。

>[!warning]
>在类外定义成员函数时，应在**返回类型和函数名之间**加上类名和::。

```cpp
class Date{
public:
    void set(int y, int m, int d);
    bool is_leap_year();
    void print();
private:
    int year, month, day;
};

void Date::set(int y, int m, int d){
    ...
}
bool is_leap_year(){
    ...
}
void Date::print(){
    ...
}
```

>[!tip]
>**成员函数的延迟定义**
>创建对象（如 A a;）的前提是类型必须是**完整类型**，即编译器已经知道该类型的**所有信息**，比如大小、成员等。
>而C++ 规定：类的成员函数（包括声明和定义）被视为**在类的完整定义之后才生效**。
>因此这样写是合法的：
>```cpp
>class A{
>public:
>    void f(){
>        A a;
>    }
>private:
>    int x, y;
>};
>```
