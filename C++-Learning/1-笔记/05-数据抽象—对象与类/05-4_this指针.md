# 05-4_this指针

## 01 定义
一般来说，类定义中描述的数据成员对该类的每个对象都有一个拷贝。而类定义中的成员函数对该类的所有对象则只有一个拷贝。那么，对于类的一个成员函数来讲，它如何知道要对哪一个对象进行操作呢？

实际上，每一个成员函数一般都有一个**隐藏的形参 this**。
```cpp
<类名> *const this;
```
在成员函数中，**对类成员的访问**是通过this来进行的。
例如
```cpp
class A{
public:
    void g(int i){
        x = i;
    }
private:
    int x, y, z;
};
A a, b;
a.g(1);
```
对于上面 A 类中的成员函数 g，编译程序将按类似于下面的形式对它进行编译:
```cpp
void g(A *const this, int i){
    this->x = i;
}
g(&a, 1);
```
