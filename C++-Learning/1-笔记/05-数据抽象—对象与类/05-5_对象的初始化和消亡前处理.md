# 05-5_对象的初始化和消亡前处理

## 01 构造函数
在使用对象前，需要对它的数据进行初始化。由于数据成员一般是**私有的**，因此不能通过对象直接对它们赋值。我们可以在对象类中提供一个实现**对象初始化的**的普通成员函数，创建对象后，通过**调用该函数**来初始化对象。

为了解决对象的初始化问题，在 C++ 中提供了一种用来对对象进行初始化的**特殊的成员函数 — 构造函数**。

### (01) 定义
构造函数（constructor）是指在对象类中定义或声明的**与类同名、无返回值类型**的成员函数。

在创建对象时，系统首先为对象分配空间，然后**自动调用**对象类的构造函数来初始化对象。
```cpp
class A{
    int x;
public:
    A() {x = 0;}
};

A a;
//  创建对象 a：为 a 分配内存空间，然后调用 a 的构造函数 A() 把 a.x 初始化为 0
```

>[!warning]
>对构造函数的调用属于对象创建过程的一部分，对象**创建之后**就**不能再调用构造函数了**。
>例如，下面的操作是错误的：
>```cpp
>a.A(); // ERROR
>```

### (02) 重载
+ **默认构造函数**：不带参数的（或所有参数都有默认值的）构造函数。其作用是在创建对象时，**如果没有指定**调用何种构造函数对其初始化，则**调用默认构造函数**。
+ **普通构造函数**：带参数的。
```cpp
class A{
    int x, y;
public:
    A(){
        x=y=0;
    }
    A(int x1){
        x = x1;
        y = 0;
    }
    A(int x1, int y1){
        x = x1;
        y = y1;
    }
};
```

上面的三个构造函数也可以用下面**带默认参数值**的构造函数来替代：
```cpp
class A{
    int x, y;
public:
    A(int x1=0, int y1=0){
        x = x1;
        y = y1;
    }
}
```

>[!warning]
>类的构造函数一般是公开的（public），但有时也把构造函数声明为私有的（private），其作用是限制创建该类对象的范围，这时，只能在本类和友元中创建该类对象。

>[!warning]
>需要注意的是，在创建动态的**对象数组**时，**只能用默认构造函数**来进行初始化。另外，如果用库函数 malloc 来创建动态对象，则系统**不会**去调用对象类的构造函数对其初始化，因此，动态对象**一般不用** malloc 来创建, 而**使用new**。

### (03) 调用
```cpp
class A
{
public:
    A();
    A(int i);
    A(char *p);
};
A a1;
A a1=A();

A a2(1);
A a2=A(1);
A a2=1;

A a3("abcd");
A a3=A("abcd");
A a3="abcd";

A a[4];
// 调用对象 a[0]、a[1]、a[2]、a[3] 的默认构造函数
A b[5] = {A(), A(1), A("abcd"), 2, "xyz"};
// 调用 b[0] 的 A()、b[1] 的 A(int)、b[2] 的 A(char *)、b[3] 的 A(int) 和 b[4] 的 A(char *)
```

### (04) 成员初始化表
对于常量数据成员和引用数据成员，不能在说明时对它们进行初始化，也不能采用赋值操作对它们进行初始化。
```cpp
class A 
{ 
    int x;
    const int y=1; // Error 
    int &z=x; // Error 
    public:
    A() 
    { x = 0; // OK 
    y = 1; // Error，y 是常量成员，其值不能改变 
    z = &x; // Error，z 不是指针
    }
};
```
在定义构造函数时，在函数头和函数体之间加入一个对数据成员进行初始化的表，称为成员初始化表，用于**对数据成员**进行初始化。
```cpp
class A {
    int x;
    const int y;
    int& z;
public:
    A(): z(x), y(1) {
        x = 0;
    }
};
```

>[!warning]
>在成员初始化表中，成员初始化的书写次序并不决定它们的初始化次序，数据成员的初始化次序**由它们在类定义中的说明次序决定**。

## 02 析构函数

### (01) 定义
析构函数（destructor）是名为“ ~< 类名 > ”且**没有参数**和**没有返回值类型**的一个特殊的**成员函数**。当对象**消亡时**，在系统收回它所占的内存空间之前，会**自动调用对象类的析构函数**。
```cpp
class A {
    int x;
public:
    A();
    ~A();
};
void f(){
    A a;
    ...
} // 调用 A 的析构函数
```

>[!warning]
>需要注意的是，在撤销动态对象数组时，如果没写 delete 操作中的“ [] ”，则只有数组中的第一个对象的析构函数会被调用。
>```cpp
>delete []p;
>delete p;
>```
>另外，如果用库函数 free 来撤销动态对象，则系统不会去调用对象类的析构函数，因此，动态对象的撤销一般不用 free 来实现。

### (02) 成员对象的初始化和消亡前处理
在创建包含成员对象的类的对象时，会自动调用**本类的默认构造函数**和**成员对象类的默认构造函数**。如果要调用成员对象类的**非默认**构造函数，则需要在本类的构造函数**成员初始化表**中显式指出。
```cpp
class A {
   int m;
public:
    A() {m = 0;}
    A(int m1) {m = m1;}
};
class B {
    int n;
    A a;
public:
    B() {n = 0;}
    B(int m1): n(0), a(m1) { }
};
B b1;
B b2(1);
```

>[!warning]
>+ 在创建含有成员对象的类的对象时，首先调用**成员对象类的构造函数**，然后再执行**本类的构造函数的函数体**。
>+ 当一个类包含多个成员对象时，对成员对象构造函数的调用次序由成员对象在类中的**说明次序来决定**，与它们在成员初始化表中的说明次序**无关**。

当包含成员对象的对象消亡时，不仅要调用本身对象的析构函数，还要调用成员对象的析构函数，它们的调用次序是：**先调用本类**的析构函数，本类的析构函数的函数体执行完后，**再调用成员对象类**的析构函数（多个的顺序与说明次序正好相反）。

## 03 拷贝构造函数
在创建一个对象时，如果用另一个同类的对象对其进行初始化，将会调用一个特殊的构造函数— 拷贝构造函数（copy constructor）。
```cpp
<类名>(const <类名>&);
A(const A& a);
```
其中 const 可以省略，加上它的目的是**防止在函数中修改实参对象**。

一般来讲，在下面三种情况下将会调用拷贝构造函数：定义对象时、**把对象作为值参数传给函数时**、**把对象作为值返回时**。
![05-5-1](/引用文件/05-5-1.png)

一般情况下，编译程序提供的隐式拷贝构造函数的行为足以满足要求，类中不需要显式定义拷贝构造函数。但是，在有些情况下如果不自定义拷贝构造函数，则将会产生设计者未意识到的严重的程序错误。

![05-5-2](/引用文件/05-5-2.png)

隐式拷贝构造函数是**浅拷贝**，对于指针成员，他只拷贝指针的值，不拷贝指针的内容。解决上面问题的办法是在类 A 中显式定义一个拷贝构造函数来实现深拷贝。
```cpp
A::A(const A& a)
{
    x = a.x;
    y = a.x;
    p = new char[strlen(a.p)+1];
    strcpy(p, a.p);
}
```
