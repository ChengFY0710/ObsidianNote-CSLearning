# 05-3_对象的创建和操作

## 01 创建对象
```cpp
class A{
public:
    void f();
    void g();
private:
    int x, y;
};
```

### 直接创建
```cpp
A a1;
A a2[100];
```
与普通变量一样，直接创建的对象也分为**全局对象**（在所有函数外定义的对象）和**局部对象**（在函数或复合语句内定义的对象），它们的**生存期和对象标识符的作用域**与相应的普通变量相同。

### 间接创建
通过 new 操作创建一个类型为某个类的的动态变量，称为**动态对象**。它们的内存空间在**堆区**中分配，用**指针变量**来标识它们。

动态对象需要用 **delete** 操作来撤销（使之消亡）。
+ 单个动态对象的创建与撤销
```cpp
A *p;
p = new A;
// 销毁
delete p;
```
+ 动态对象数组的创建与撤销
```cpp
A *p;
p = new A[100];
// 撤销
delete []p;
```

>[!warning]
>动态对象一般不使用malloc和free来创建和撤销

### 成员对象的创建
由于一个类的数据成员的类型可以是另一个类，因此一个对象可以**包含**另一个对象——成员对象。
```cpp
class A{
    ....
};
class B{
    A a;
    ....
};
B b;
```
>[!tip]
>成员对象的生存期与包含它的对象相同，即成员对象随包含它的对象一起创建、一起消亡。

## 02 对象的操作
```cpp
class A{
    int x;
public:
    void f();
};
int main()
{
    A a;
    a.f();
    A *p = new A;
    p->f();
    delete p;
    return 0;
}
```
