## 01 压缩存储
**压缩存储**：为多个值**相同**的元素或值为 **0** 的元素只分配**一个**存储空间，对**不重复**的元素才分配空间。
+ **特殊矩阵**：矩阵中非零元素的分布有一定**规律**（如对称矩阵、三角矩阵、对角矩阵）。
+ **稀疏矩阵**：非零元素个数远远少于矩阵元素总数，且分布**没有规律**。

>[!note]
>压缩存储的原则：只给**不重复**的元素分配存储空间，重复元素/零元素**共享**一个空间或**不占**空间。

## 02 对称矩阵
**对称矩阵**：满足 `aij = aji`（`0 <= i, j <= n-1`）的 n 阶方阵。
+ 只需存储**下三角**（或上三角）部分的 `n(n+1)/2` 个元素。
+ 使用一维数组 `sa[n(n+1)/2]` 存储，**按行优先**存放原矩阵的下三角部分。

### （1）下标映射（行优先存下三角，下标从 0 开始）
当 `i >= j`（下三角及对角线元素）：
```
k = i * (i + 1) / 2 + j
```
当 `i < j`（上三角元素，由对称性 `aij = aji`）：
```
k = j * (j + 1) / 2 + i
```

### （2）特点
+ **优点**：节省约一半存储空间，且仍可**随机存取**任意元素。
+ **缺点**：只适用于**对称**矩阵，通用性差。

## 03 三角矩阵
**三角矩阵**：主对角线以上（或以下）的元素**全部相同**（通常为常量 `c`）的 n 阶方阵。
+ **下三角矩阵**：下三角部分为不同值，上三角部分全为常量 `c`。
+ **上三角矩阵**：上三角部分为不同值，下三角部分全为常量 `c`。

### （1）存储方法
一维数组 `sa[n(n+1)/2 + 1]`，前 `n(n+1)/2` 个位置按**行优先**存放三角部分，**最后一个位置**存放常量 `c`。

### （2）下三角矩阵的下标映射（下标从 0 开始）
当 `i >= j`：`k = i * (i + 1) / 2 + j`
当 `i < j`：`k = n * (n + 1) / 2`（常量 `c` 的位置）

## 04 对角矩阵（带状矩阵）
**对角矩阵**：所有非零元素都集中在主对角线附近的矩阵。以**三对角矩阵**为例，非零元素满足 `|i - j| <= 1`。

### （1）存储方法
只存放三条对角线上的 `3n - 2` 个元素，按**行优先**存入一维数组 `sa[3n - 2]`（下标从 0 开始）。

### （2）下标映射
对于第 `i` 行（`0 < i < n-1`），前 `i` 行共存放 `3i - 1` 个元素，本行中 `aij` 排在第 `j - i + 1` 位，故：
```
k = 3 * i - 1 + (j - i + 1) = 2 * i + j
```

>[!tip]
>特殊矩阵压缩存储的核心都是：找到**二维下标 (i, j)** 到**一维下标 k** 的**映射公式**，并且仍能**随机存取**。
