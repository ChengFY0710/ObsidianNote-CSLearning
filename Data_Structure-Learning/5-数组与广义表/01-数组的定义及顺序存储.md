## 01 数组的定义
数组是由**相同类型**的数据元素构成的**有限集合**，其中每个元素受**一组下标**约束。
+ **一维数组**：n 个元素的有限序列，可看作是线性表的推广。
+ **二维数组**：可看作是以**一维数组为元素**的一维数组，即矩阵。
+ **多维数组**：可递归定义为以低一维数组为元素的一维数组。

>[!note]
>数组一旦建立，其**元素个数**和**元素间的关系**一般不再发生变化，因此数组上只定义**存取元素**和**修改元素**的操作，没有插入、删除操作。

## 02 数组的顺序存储
由于数组没有插入和删除运算，通常采用**顺序存储结构**。
+ **存储特点**：把数组元素**依次连续存放**在一片地址连续的存储单元中。
+ **存储方式**：只要给出数组的**起始地址**（基址）和**下标**，即可求得元素的**存储地址**，因此数组也是**随机存取**的存储结构。

### （1）一维数组
设一维数组 `A[n]`，每个元素占 `size` 个存储单元，基址为 `LOC(a0)`，则：
```cpp
LOC(ai) = LOC(a0) + i * size    (i = 0, 1, ..., n-1)
```

### （2）二维数组（行优先）
设二维数组 `A[m][n]`，按**行优先**存储（C/C++、Pascal 采用），即先存第 0 行，再存第 1 行……每行从左到右依次存放。则：
```cpp
LOC(aij) = LOC(a00) + (i * n + j) * size    (0 <= i <= m-1, 0 <= j <= n-1)
```
### （3）二维数组（列优先）
按**列优先**存储（FORTRAN 采用），即先存第 0 列，再存第 1 列……每列从上到下依次存放。则：
```cpp
LOC(aij) = LOC(a00) + (j * m + i) * size
```

>[!tip]
>行优先地址公式规律：**跳过整行**（`i*n`）再**跳过列**（`j`）；列优先则相反，**跳过整列**（`j*m`）再**跳过行**（`i`）。

### （4）推广到多维数组
n 维数组按**最右边下标优先**（即行优先的推广）连续存放，设各维长度为 `b1, b2, ..., bn`，则元素 `aj1j2...jn` 的地址为：
```cpp
LOC(aj1j2...jn) = LOC(a00...0) + (j1*b2*b3*...*bn + j2*b3*...*bn + ... + jn-1*bn + jn) * size
```
其中 `dj = dj+1 * bi+1`（`dn = 1`）称为**位移量**，计算方式与顺序表类似。
