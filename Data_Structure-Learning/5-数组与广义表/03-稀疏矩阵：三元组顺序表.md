## 01 稀疏矩阵
设 m 行 n 列的矩阵中有 **t** 个非零元素，若 `t << m * n`，则称该矩阵为**稀疏矩阵**（一般 `t < m * n / 6` 时可认为是稀疏矩阵）。

>[!note]
>稀疏矩阵中零元素多且分布**没有规律**，不能用前面特殊矩阵的下标映射法压缩，通常只存储**非零元素**。

## 02 三元组顺序表
### （1）三元组
稀疏矩阵中的每个非零元素用一个**三元组**唯一确定：
```
(i, j, v)    // 行下标、列下标、元素值
```
其中 `0 <= i <= m-1`，`0 <= j <= n-1`。

### （2）存储结构
将所有非零元素的三元组按**行优先**（或列优先）顺序依次存放在一组地址连续的存储单元中，即得到**三元组顺序表**（又称**顺序三元组表**）。

```cpp
#define MAXSIZE 10000    // 非零元素个数上限
typedef int ElemType;

typedef struct {
	int i, j;            // 该非零元素的行、列下标
	ElemType e;          // 该非零元素的值
} Triple;

typedef struct {
	Triple data[MAXSIZE + 1];   // data[0] 存放矩阵的行数、列数、非零元个数
	int mu, nu, tu;             // 矩阵的行数、列数、非零元个数
} TSMatrix;
```

>[!tip]
>`data[0]` 通常作为**表头**，存放矩阵的总行数 `mu`、总列数 `nu` 和非零元素个数 `tu`，非零元素从 `data[1]` 开始按**行序递增**存放。

### （3）特点
+ **优点**：实现简单，可节省大量空间，便于按行处理，转置等运算容易实现。
+ **缺点**：不能随机存取某个指定元素（只能顺序查找）；插入、删除元素需要移动大量三元组。
+ 适用于**非零元素个数较少**且**修改不频繁**的稀疏矩阵。

## 03 稀疏矩阵的转置
将稀疏矩阵 `M` 的行、列互换得到其**转置矩阵** `T`。

### （1）简单转置算法
依次扫描三元组表中每个三元组，将 `(i, j, e)` 变为 `(j, i, e)` 存入转置后的表中，但这样得到的三元组**没有按行序排列**，所以需要**按列扫描**：对原表**按列号从小到大**扫描，将每个三元组的行列互换后依次放入。
+ **时间复杂度**：`O(n * tu)`（外层循环列号，内层扫描全部三元组）
+ **空间复杂度**：`O(n)`

```cpp
Status TransposeSMatrix(TSMatrix M, TSMatrix &T) {
	T.mu = M.nu;  T.nu = M.mu;  T.tu = M.tu;
	if (T.tu == 0) return OK;

	q = 1;
	for (col = 1; col <= M.nu; ++col)        // 按列号递增扫描
		for (p = 1; p <= M.tu; ++p)          // 扫描整个三元组表
			if (M.data[p].j == col) {
				T.data[q].i = M.data[p].j;
				T.data[q].j = M.data[p].i;
				T.data[q].e = M.data[p].e;
				++q;
			}
	return OK;
}
```

### （2）快速转置算法
预先**统计**原矩阵**每一列**中非零元素的个数 `num[col]`，由此求出转置矩阵**每一行**的**起始位置** `cpot[col]`，再**一次扫描**原三元组表即可按行序放入正确位置。

```cpp
// 求第 col 列第一个非零元素在 T.data 中的位置
cpot[1] = 1;
for (col = 2; col <= M.nu; ++col)
	cpot[col] = cpot[col - 1] + num[col - 1];
```

```cpp
Status FastTransposeSMatrix(TSMatrix M, TSMatrix &T) {
	T.mu = M.nu;  T.nu = M.mu;  T.tu = M.tu;
	if (T.tu == 0) return OK;

	for (col = 1; col <= M.nu; ++col) num[col] = 0;
	for (k = 1; k <= M.tu; ++k)        // 统计各列非零元素个数
		++num[M.data[k].j];

	cpot[1] = 1;                        // 求各列第一个元素的目标位置
	for (col = 2; col <= M.nu; ++col)
		cpot[col] = cpot[col - 1] + num[col - 1];

	for (p = 1; p <= M.tu; ++p) {       // 一次扫描完成转置
		col = M.data[p].j;
		q = cpot[col];
		T.data[q].i = M.data[p].j;
		T.data[q].j = M.data[p].i;
		T.data[q].e = M.data[p].e;
		++cpot[col];
	}
	return OK;
}
```

**算法分析**：
+ 初始化 `num`、`cpot` 的时间复杂度为 `O(n + tu)`，一次扫描为 `O(tu)`，总时间复杂度为 `O(n + tu)`。
+ 相比简单转置的 `O(n * tu)`，当 `tu` 很大时效率显著提高，属于典型的**以空间换时间**。

>[!note]
>`num[col]`：第 col 列非零元素个数；`cpot[col]`：第 col 列第一个非零元素在转置后三元组表中的位置。二者满足 `cpot[col] = cpot[col-1] + num[col-1]`。

## 04 稀疏矩阵的基本运算（选读）
以**矩阵相乘** `Q = M × N` 为例，用三元组表实现时，按 `M` 的**行**依次扫描，对 `M` 的每个非零元素 `mik`，在 `N` 中查找第 `k` 行的非零元素累加到 `Q` 的第 `i` 行。
+ **时间复杂度**：`O(M.tu * N.tu)`（最坏情况），不如按二维数组直接相乘的 `O(m * n * l)` 有针对性。
+ 因此三元组表**牺牲了随机存取**，只在特定运算和存储受限时更有优势。
