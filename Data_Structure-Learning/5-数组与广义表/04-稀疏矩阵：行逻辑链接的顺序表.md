## 01 行逻辑链接的顺序表
**行逻辑链接的顺序表（Row Logic Linked Sequential List）** 是在三元组顺序表的基础上增加一个**行位置表** `rpos[]` 得到的顺序存储结构。
+ 三元组顺序表中的 `data[]` 虽按**行优先**存放，但只能顺序扫描，**无法直接定位**某一行从哪个位置开始。
+ `rpos[i]` 记录第 `i` 行**第一个非零元素**在 `data[]` 中的下标，相当于用数组把每一行的起始位置"链接"起来。
+ 借助 `rpos[]`，可在 `O(1)` 时间内找到任意一行的非零元素区间，特别适合**按行处理**的矩阵运算。

>[!note]
>它仍属于**顺序存储**，"链接"不是指针，而是 `rpos[]` 中记录的下标；与三元组顺序表相比只多了一个 `rpos[]` 数组。

### （1）例子
设有 4 行 4 列的稀疏矩阵：

| 行\列 | 1   | 2   | 3   | 4   |
| --- | --- | --- | --- | --- |
| 1   | 0   | 12  | 9   | 0   |
| 2   | 0   | 0   | 0   | 0   |
| 3   | -3  | 0   | 0   | 14  |
| 4   | 0   | 0   | 24  | 0   |

按行优先存放的三元组表：

| `t` | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- |
| `data[t]` | (1,2,12) | (1,3,9) | (3,1,-3) | (3,4,14) | (4,3,24) |

对应的行位置表（`tu = 5`，`rpos[5] = tu + 1 = 6` 为哨兵）：

| `i`       | 1   | 2   | 3   | 4   | 5   |
| --------- | --- | --- | --- | --- | --- |
| `rpos[i]` | 1   | 3   | 3   | 5   | 6   |

+ 第 1 行：`[rpos[1], rpos[2]) = [1, 3)`，即 `data[1..2]`。
+ 第 2 行：`[3, 3)`，区间为空，说明该行没有非零元素。
+ 第 3 行：`[3, 5)`，即 `data[3..4]`。
+ 第 4 行：`[5, 6)`，即 `data[5]`。

## 02 存储结构
```cpp
#define MAXSIZE 10000    // 非零元素个数上限
#define MAXRC 100        // 矩阵最大行数

typedef struct {
	int i, j;            // 该非零元素的行、列下标
	ElemType e;          // 该非零元素的值
} Triple;

typedef struct {
	Triple data[MAXSIZE + 1];   // 非零元素从 data[1] 开始按行优先存放
	int rpos[MAXRC + 2];        // rpos[i]：第 i 行第一个非零元素在 data 中的位置（含哨兵）
	int mu, nu, tu;             // 矩阵的行数、列数、非零元素个数
} RLSMatrix;
```

>[!tip]
>`rpos[]` 的长度为 `mu + 1`，其中 `rpos[1..mu]` 有效，`rpos[mu+1]` 作为**哨兵**存放 `tu + 1`。这样第 `i` 行的非零元素区间可统一表示为 `[rpos[i], rpos[i+1])`，无需对最后一行单独判断。

## 03 求 rpos 数组
**算法思路**：
+ 先统计每一行的非零元素个数 `num[row]`。
+ 再求前缀和：第 `row` 行的起始位置 = 上一行的起始位置 + 上一行的非零元素个数。

```cpp
void GetRPos(RLSMatrix &M) {
	for (row = 1; row <= M.mu; ++row) num[row] = 0;
	for (t = 1; t <= M.tu; ++t)              // 统计各行非零元素个数
		++num[M.data[t].i];

	M.rpos[1] = 1;
	for (row = 2; row <= M.mu; ++row)        // 前缀和求各行起始位置
		M.rpos[row] = M.rpos[row - 1] + num[row - 1];
	M.rpos[M.mu + 1] = M.tu + 1;             // 哨兵：第 mu 行的结束位置
}
```

**算法分析**：时间复杂度为 `O(mu + tu)`，空间复杂度为 `O(mu)`。由于 `data[]` 已按行优先有序，只需统计和累加，不必排序。

>[!note]
>若某行没有非零元素，则 `rpos[row] = rpos[row + 1]`，该行区间 `[rpos[row], rpos[row+1])` 为空。例如上面的第 2 行，`rpos[2] = rpos[3] = 3`。

## 04 基于行逻辑链接的矩阵乘法
矩阵相乘 `Q = M × N` 要求 `M.nu == N.mu`，且
```
Q[i][j] = Σ M[i][k] * N[k][j]    (1 <= k <= M.nu)
```

**算法思路**：
+ 按 `M` 的**行**依次处理，用累加器数组 `ctemp[1..N.nu]` 存放 `Q` 当前行各列的部分和。
+ 对 `M` 第 `i` 行的每个非零元素 `(i, k, v)`，用 `N.rpos[k]` 直接定位 `N` 的第 `k` 行，把 `v * N[k][j]` 累加到 `ctemp[j]`。
+ 本行处理完后，将 `ctemp[]` 中的非零值压缩成三元组依次存入 `Q.data[]`，并记下 `Q.rpos[i]`。

```cpp
Status MultSMatrix(RLSMatrix M, RLSMatrix N, RLSMatrix &Q) {
	if (M.nu != N.mu) return ERROR;

	Q.mu = M.mu;  Q.nu = N.nu;  Q.tu = 0;
	for (arow = 1; arow <= M.mu; ++arow) {
		for (ccol = 1; ccol <= Q.nu; ++ccol) ctemp[ccol] = 0;  // 累加器清零
		Q.rpos[arow] = Q.tu + 1;                               // Q 第 arow 行的起始位置

		for (p = M.rpos[arow]; p < M.rpos[arow + 1]; ++p) {    // 扫描 M 的第 arow 行
			brow = M.data[p].j;                                // 对应 N 的第 brow 行
			for (q = N.rpos[brow]; q < N.rpos[brow + 1]; ++q) {
				ccol = N.data[q].j;
				ctemp[ccol] += M.data[p].e * N.data[q].e;
			}
		}

		for (ccol = 1; ccol <= Q.nu; ++ccol)                   // 压缩本行非零元
			if (ctemp[ccol]) {
				if (++Q.tu > MAXSIZE) return ERROR;
				Q.data[Q.tu].i = arow;
				Q.data[Q.tu].j = ccol;
				Q.data[Q.tu].e = ctemp[ccol];
			}
	}
	Q.rpos[Q.mu + 1] = Q.tu + 1;                               // 设置哨兵
	return OK;
}
```

**算法分析**：
+ 初始化累加器：`O(M.mu × N.nu)`。
+ 扫描 `M` 的每个非零元素，并遍历 `N` 中对应的一行；若 `N` 各行平均有 `N.tu / N.mu` 个非零元素，则这部分平均为 `O(M.tu × N.tu / N.mu)`，最坏为 `O(M.tu × N.tu)`。
+ 总时间复杂度为 `O(M.mu × N.nu + M.tu × N.tu / N.mu)`，空间复杂度为 `O(N.nu)`（不计结果矩阵）。
+ 与三元组顺序表直接相乘的 `O(M.tu × N.tu)` 相比，`rpos[]` 省去了每次查找 `N` 第 `k` 行时从头扫描的开销。

>[!tip]
>若 `N` 的某一行没有非零元素，则 `N.rpos[brow] == N.rpos[brow + 1]`，内层循环自动跳过，不需要额外判断。

## 05 特点
+ **优点**：存储紧凑；通过 `rpos[]` 实现按行随机定位，按行运算（尤其是矩阵乘法）效率高。
+ **缺点**：只索引了行，按列访问仍需扫描；插入、删除非零元素要移动三元组，不适合频繁修改。
+ **适用场景**：非零元素较少、矩阵规模较大且**按行处理**的静态稀疏矩阵。

### （1）三种存储结构的比较
| | 三元组顺序表 | 行逻辑链接顺序表 | 十字链表 |
| --- | --- | --- | --- |
| 存储方式 | 顺序存储 | 顺序存储 | 链式存储 |
| 行定位 | 从头扫描 | `rpos[]` 直接定位 | 行链表头指针 |
| 列定位 | 从头扫描 | 从头扫描 | 列链表头指针 |
| 插入/删除 | 需移动元素 | 需移动元素 | 修改指针即可 |
| 适用场景 | 转置等整体运算 | 按行处理、矩阵乘法 | 元素频繁变动 |
