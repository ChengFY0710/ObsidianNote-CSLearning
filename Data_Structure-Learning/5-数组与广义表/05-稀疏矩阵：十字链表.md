## 01 十字链表
**十字链表（Orthogonal List）** 是稀疏矩阵的**链式存储结构**。
+ 非零元素既挂在所在**行链表**上，又挂在所在**列链表**上，形成"十字"交叉的链式结构。
+ 适用于**非零元素个数经常变化**（插入、删除频繁）的稀疏矩阵。

>[!note]
>三元组顺序表**适合"静"**（元素稳定、按行处理）；十字链表**适合"动"**（频繁修改）。

## 02 存储结构
### （1）结点结构
每个非零元素用一个结点表示，包含 5 个域：

| 域 | 含义 |
| --- | --- |
| `i` | 行下标 |
| `j` | 列下标 |
| `e` | 元素值 |
| `right` | 指向同一行的下一个非零元素 |
| `down` | 指向同一列的下一个非零元素 |

```cpp
typedef struct OLNode {
	int i, j;              // 该非零元素的行、列下标
	ElemType e;            // 元素值
	struct OLNode *right;  // 指向同一行的下一个非零元素
	struct OLNode *down;   // 指向同一列的下一个非零元素
} OLNode, *OLink;
```

### （2）头结点数组
设置一个一维数组 `rhead[m]` 和 `chead[n]`，分别存放**各行链表**和**各列链表**的**头指针**，头结点的 `i`、`j`、`e` 域分别存放矩阵的**行数、列数、非零元素个数**。

```cpp
typedef struct {
	int mu, nu, tu;        // 矩阵的行数、列数、非零元素个数
	OLink *rhead, *chead;  // 行链表、列链表头指针数组
} CrossList;
```

## 03 十字链表的创建算法
以**按行**输入非零元素建立十字链表为例。

**算法思路**：
+ **初始化**：创建头结点数组 `rhead[]`、`chead[]`，置空链表。
+ **生成结点**：读入一个非零元素 `(i, j, e)`，生成新结点。
+ **行插入**：在第 `i` 行链表中按**列号递增**顺序找到插入位置，链接 `right` 指针。
+ **列插入**：在第 `j` 列链表中按**行号递增**顺序找到插入位置，链接 `down` 指针。

```cpp
Status CreateSMatrix_OL(CrossList &M) {
	scanf("%d %d", &M.mu, &M.nu);
	M.rhead = (OLink*)malloc((M.mu + 1) * sizeof(OLink));
	M.chead = (OLink*)malloc((M.nu + 1) * sizeof(OLink));
	for (k = 1; k <= M.mu; ++k) M.rhead[k] = NULL;
	for (k = 1; k <= M.nu; ++k) M.chead[k] = NULL;

	scanf("%d", &M.tu);
	for (k = 1; k <= M.tu; ++k) {
		scanf("%d %d %d", &i, &j, &e);
		p = (OLink)malloc(sizeof(OLNode));
		p->i = i;  p->j = j;  p->e = e;

		// 行插入：找到第 i 行中列号小于 j 的最后一个结点
		if (!M.rhead[i] || M.rhead[i]->j > j) {
			p->right = M.rhead[i];
			M.rhead[i] = p;
		} else {
			for (q = M.rhead[i]; q->right && q->right->j < j; q = q->right);
			p->right = q->right;
			q->right = p;
		}

		// 列插入：找到第 j 列中行号小于 i 的最后一个结点
		if (!M.chead[j] || M.chead[j]->i > i) {
			p->down = M.chead[j];
			M.chead[j] = p;
		} else {
			for (q = M.chead[j]; q->down && q->down->i < i; q = q->down);
			p->down = q->down;
			q->down = p;
		}
	}
	return OK;
}
```

## 04 两种稀疏矩阵存储结构的比较
| | 三元组顺序表 | 十字链表 |
| --- | --- | --- |
| 存储方式 | 顺序存储 | 链式存储 |
| 随机存取 | 不可 | 不可 |
| 插入/删除 | 需移动元素 | 修改指针即可 |
| 适用场景 | 元素稳定、批量处理 | 元素频繁变动 |
| 空间开销 | 紧凑 | 每个结点多 2 个指针 |
