## 01 广义表的定义
**广义表（Generalized List）** 是 n 个元素的**有限序列**，元素可以是**原子**（不可再分的单个元素），也可以是另一个**广义表**（子表）。
```
LS = (a1, a2, ..., an)
```
+ **原子（atom）**：广义表中**不可再分**的元素，是一个简单的数据对象。
+ **子表（sublist）**：广义表中**可以再分**的元素，它本身又是一个广义表。
+ **表头（Head）**：非空广义表的**第一个元素** `a1`。
+ **表尾（Tail）**：除去表头后**其余元素构成的子表** `(a2, ..., an)`。
+ **长度**：广义表中**元素的个数**（顶层元素个数）。
+ **深度（层数）**：广义表中**括号的最大嵌套层数**，空表深度为 1（或 0，依定义而定）。

### （1）例子
| 广义表 | 长度 | 深度 | 表头 | 表尾 |
| --- | --- | --- | --- | --- |
| `()` 空表 | 0 | 1 | — | — |
| `(a)` | 1 | 1 | `a` | `()` |
| `((a), (b), (c))` | 3 | 2 | `(a)` | `((b), (c))` |
| `(a, (b, c), d)` | 3 | 2 | `a` | `((b, c), d)` |

>[!tip]
>+ 表头可以是**原子**，也可以是**子表**；但**表尾一定是子表**。
>+ 广义表可以**共享**和**递归**：如 `LS = (a, LS)` 是递归表。
>+ **多维数组**可以看作广义表的推广，广义表是线性表的推广。

## 02 广义表的存储结构
由于广义表中的元素**类型不统一**（原子与子表混杂），通常采用**链式存储**。

### （1）头尾链表存储
每个元素（原子或子表）用一个**结点**表示，结点含 3 个域：

| 域 | 含义 |
| --- | --- |
| `tag` | `0` 表示原子，`1` 表示子表 |
| `atom` / `ptr.hp` | 原子值，或指向**表头**结点的指针 |
| `tp` / `ptr.tp` | 指向**下一个元素（表尾）**结点的指针 |

```cpp
typedef enum { ATOM, LIST } ElemTag;   // ATOM=0 原子，LIST=1 子表

typedef struct GLNode {
	ElemTag tag;                       // 元素类型
	union {
		AtomType atom;                 // 原子值
		struct {
			struct GLNode *hp;         // 指向表头
			struct GLNode *tp;         // 指向表尾
		} ptr;
	};
} GLNode, *GList;
```

>[!note]
>一个广义表 `LS = (a1, a2, ..., an)` 在头尾链表中表示为：**表头指针指向 a1 的结点**，a1 的 `tp` 指向 a2 的结点……an 的 `tp` 为 `NULL`。**空表的头指针为 NULL**。

### （2）扩展线性表存储
将原子和子表统一成一种结点结构：`tag`、`atom/hp`、`tp` 三个域合并为 `tag`、`data`、`tp`，子表的 `data` 域用 `hp` 指向子表第一个元素。
+ 所有元素（包括表本身）都用**同一种结点**表示，结构更统一。
+ 便于实现广义表的**递归运算**。

## 03 广义表的基本运算
+ **GetHead(LS)**：取表头，返回第一个元素（原子或子表）。
+ **GetTail(LS)**：取表尾，返回去掉第一个元素后的子表。
+ **Length(LS)**：求长度，沿 `tp` 链扫描计数。
+ **Depth(LS)**：求深度，递归求各子表深度，取最大值加 1。
+ **Copy(LS)**：复制广义表。
+ **Insert / Delete**：插入、删除子表元素。

```cpp
// 取表头
GLNode* GetHead(GList LS) {
	if (!LS) return NULL;       // 空表无表头
	return LS;                  // 头尾链表中 LS 即指向表头结点
}

// 取表尾
GLNode* GetTail(GList LS) {
	if (!LS) return NULL;
	return LS->ptr.tp;          // 表头结点的 tp 指向表尾
}
```

### （1）求广义表深度（递归）
**算法思路**：
+ 空表深度为 1，原子深度为 0。
+ 对表中每个元素：若是原子，深度记 0；若是子表，递归求其深度。
+ 整表深度 = 各元素深度的**最大值 + 1**。

```cpp
int GListDepth(GList LS) {
	if (!LS) return 1;                    // 空表
	if (LS->tag == ATOM) return 0;        // 原子
	max = 0;
	for (p = LS; p; p = p->ptr.tp) {      // 遍历表中所有元素
		dep = GListDepth(p->ptr.hp);      // 递归求子表深度
		if (dep > max) max = dep;
	}
	return max + 1;
}
```

>[!note]
>广义表的运算大多采用**递归**实现，因为广义表本身就是**递归定义**的数据结构；也有相应的**非递归**算法（借助栈实现）。
