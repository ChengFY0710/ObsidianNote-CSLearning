## 01 基本概念
子串的定位操作，又称为**模式匹配（Pattern Matching）** 或**串匹配（String Matching）**，其中**子串**被称为**模式串**。
主串：S，模式串：T

## 02 朴素算法
![[引用文件/DataStructure-Learning/3-03-1.png|412]]
```cpp
int Index(SString S, SString T, int pos){
	i = pos; j = 1;
	while(i <= S[0] && j <= T[0]){
		if(S[i] == T[j]){++i; ++j;}
		else{i = i-j+2; j = 1;} // 指针后退重新开始匹配。
	}
	if(j>T[0]) return i-T[0]; // j>T[0]则匹配成功。
	else return 0;	
}
```

## 03 KMP算法

![[引用文件/DataStructure-Learning/3-03-2.png]]

```cpp
int Index_KMP(SString S, SString T, int pos) {
    // 利用模式串T的next函数求T在主串S中第pos个字符之后的
    //位置的KMP算法，其中，T非空，1≤pos≤StrLength(S)。
    i = pos;  j = 1;
    while (i <= S[0] && j <= T[0]) {
        if (j == 0 || S[i] == T[j]) { ++i; ++j; }
                            // 继续比较后继字符
        else j = next[j];    // 模式串向右移动
    }
    if (j > T[0]) return i-T[0];  // 匹配成功
    else return 0;
} // Index_KMP
```

>[!note]
>j=0 => 主串遍历 i 和子串遍历 j 同时后移，因为==🟢j为0标志着**子串第一个失配**，相当于此时要**移动主串**==。
>j=1 => ==🟢j为1标志着子串**非第一个失配，且无相同前后缀**，此时**不移动主串**，移动子串，重新开始。==

**求next函数方法**：

![[引用文件/DataStructure-Learning/3-03-4.png|409]]
```cpp
void get_next(SString &T, int &next[])
{
    // 求模式串T的next函数值并存入数组next
    i = 1;  next[1] = 0;  j = 0;
    while (i < T[0]) {
        if (j == 0 || T[i] == T[j])
        {
            ++i;  ++j; next[i] = j;
        }
        else j = next[j];
    }
} // get_next
```

>[!note]
>1. **`j` 代表“前缀”的位置**：j 指向的是模式串开头（前缀）的某个字符。在求 `next` 数组的过程中，`j` 实际上记录了**当前已经匹配上的最长相等前后缀的长度**。
>2. **`i` 代表“后缀”的位置**：i 指向的是模式串当前位置（后缀）的某个字符，它正在向后扫描。

**改进算法**：
![[引用文件/DataStructure-Learning/3-03-5.png|366]]
```cpp
void get_nextval(SString &T, int &nextval[])
{
    // 求模式串T的next函数修正值并存入数组nextval.
    i = 1; nextval[1] = 0; j = 0;
    while (i < T[0]) {
        if (j == 0 || T[i] == T[j]) {
            ++i; ++j;
            if (T[i] != T[j]) nextval[i] = j;
            else nextval[i] = nextval[j];
        }
        else j = nextval[j];
    }
} // get_nextval
```
