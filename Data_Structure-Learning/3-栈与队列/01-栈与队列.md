## 01 栈
+ **定义**：只能在**表的一端**进行插入和删除运算的**线性表**。
+ **逻辑结构**：与线性表相同，仍为**一对一**的关系。
+ **存储结构**：用**顺序栈**或**链栈**存储均可。
+ **运算规则**：只能在**栈顶**运算，且访问节点按照**后进先出（LIFO）** 的原则
+ **实现方式**：关键是编写**入栈**和**出栈**函数，具体实现依顺序栈或链栈的不同而不同。

```cpp
#define MAXSIZE 100
typedef struct{
	ElemType *base;
	ElemType *top;
	int stackSize;
}Stack;

Status InitStack(Stack &S){
	S.base = new ElemType[MAXSIZE];
	if(!S.base) return OVERFLOW; // 空间分配失败
	S.top = S.base;
	S.stackSize = MAXSIZE;
	return OK;
}

bool StackEmpty(Stack S){
	if(S.top == S.base) return true;
	else return false;
}

int StackSize(Stack S){
	return S.top - S.base;
}

Status Push(Stack &S, ElemType e){
	if(S.top - S.base == S.stackSize) return ERROR; // 栈满
	*S.top++ = e;
	return OK;
}

Status Pop(Stack &S, ElemType &e){
	if(S.top == S.base) return ERROR; //栈空
	e = *--S.top;
	return OK;
}

```

### （1）链栈
采用单链表来存储栈中的元素，只在**链表头部**进行插入和删除，故不必附设头节点。链表的**头指针**就是栈顶指针。
```cpp
typedef struct StackNode{
	SElemType data;
	struct StackNode *next;
}*Link;
typedef struct{
	Link top;
}LinkStack;

//初始化
Status InitStack(LinkStack &S){
	S.top = NULL;
	return OK;
}

//判空
Status StackEmpty(LinkStack S){
	return S.top == NULL;
}

//取栈顶元素
Status GetTop(LinkStack S, SElemType &e){
	if(StackEmpty(S)) return ERROR;
	e = S.top->data;
	return OK;
}

//进栈
Status Push(LinkStack &S, SElemType e){
	q = (Link)malloc(sizeof(StackNode));
	if(!q) return ERROR;
	q->data = e;
	q->next = S.top;
	S.top = q;
	return OK;
}

//出栈
Status Pop(LinkStack &S, SElemType &e){
	q = S.top;
	if(StackEmpty(S)) return ERROR;
	e = q->data;
	S.top = q->next;
	free(q);
	return OK;
}
```

## 02 队列
+ **定义**：只能给你在表的尾部插入，表的头部删除的**线性表**。
+ **逻辑结构**：与线性表相同，仍为**一对一**的关系。
+ **存储结构**：用**顺序队**或**链队**存储均可。
+ **运算规则**：**先进先出（FIFO）**
+  **实现方式**：关键是编写**入队**和**出队**函数，具体实现依顺序栈或链栈的不同而不同。

### （1）循环队列
在循环队列中进行出队、入队操作时,头尾指针仍要
加1,朝前移动。只不过当头尾指针指向向量上界
(QueueSize-1)时,其加1操作的结果是指向向量的
下界0。
这种循环意义下的加1操作可以描述为:
```cpp
if(i+1==QueueSize)

i++;
```

### （2）链队列
单链表，设置两个指针表示**队头队尾**
链队列添加一个**头节点**，并令**头指针指向头节点**
```cpp
typedef struct QNode{
	QElemType data;
	struct QNode *next;
}QNode, *QueuePtr;
typedef struct{
	QueuePtr front;
	QueuePtr rear;
}LinkQueue;

// 创建空队列
Status InitQueue(LinkQueue &Q){
	Q.front = Q.rear = (QueuePtr)malloc(sizeof(QNode));
	if(!Q.front) return ERROR;
	Q.front->next  = NULL;
	return OK;
}

// 销毁队列
Status DestroyQueue(LinkQueue &Q){
	while(Q.front){
		Q.rear = Q.front->next;
		free(Q.front);
		Q.front = Q.rear;
	}
	return OK;
}

// 入队列
Status EnQueue(LinkQueue &Q, QElemType e){
	p = (QueuePtr)malloc(sizeof(QNode));
	if(!p) return ERROR;
	p->data = e;
	p->next = NULL;
	Q.rear->next = p;
	Q.rear = p;
	return OK;
}

// 出队列
Status DeQueue(LinkQueue &Q, QElemType &e){
	if(Q.front == Q.rear) return ERROR;
	p = Q.front->next;
	e = p->data;
	Q.front->next = p->next;
	if(Q.rear == p) Q.rear = Q.front;
	free(p);
	return OK;
}
```
