## 01 线索二叉树的定义
**线索二叉树（Threaded Binary Tree）**：利用二叉链表中**空的指针域**存放结点在某种遍历次序下的**前驱**和**后继**信息，这些指针称为**线索（thread）**，加上线索的二叉树称为线索二叉树。

+ 具有 n 个结点的二叉链表共有 `2n` 个指针域，其中 `n-1` 个用于指向孩子，剩余的 `n+1` 个为空指针域。
+ 约定：
  + `LTag = 0`：`lchild` 指向**左孩子**；`LTag = 1`：`lchild` 指向**前驱**。
  + `RTag = 0`：`rchild` 指向**右孩子**；`RTag = 1`：`rchild` 指向**后继**。
+ 按遍历次序不同，分为**先序线索二叉树**、**中序线索二叉树**、**后序线索二叉树**。

**结点结构**：

| LTag | lchild | data | rchild | RTag |
| --- | --- | --- | --- | --- |
| 0/1 | 左孩子或前驱 | 数据域 | 右孩子或后继 | 0/1 |

```cpp
typedef enum { Link, Thread } PointerTag;  // Link=0 指向孩子，Thread=1 指向前驱/后继
typedef struct BiThrNode {
	TElemType data;
	struct BiThrNode *lchild, *rchild;
	PointerTag LTag, RTag;
} BiThrNode, *BiThrTree;
```

>[!note]
>线索化就是把遍历过程中结点的**前驱、后继**关系保存下来，本质上是把二叉树变成一条**双向链表**，从而可以**不用栈、不用递归**地遍历。

## 02 中序线索化
**算法思路**：按中序遍历的顺序，用指针 `pre` 记录刚访问过的结点。
+ 若当前结点 `p` 的左孩子为空，令 `p->LTag = Thread`，`p->lchild = pre`。
+ 若 `pre` 的右孩子为空，令 `pre->RTag = Thread`，`pre->rchild = p`。
+ 处理完后令 `pre = p`。

```cpp
BiThrTree pre = NULL;  // 全局变量，始终指向刚访问过的结点

void InThreading(BiThrTree p) {
	if (p) {
		InThreading(p->lchild);           // 线索化左子树
		if (!p->lchild) {                 // 左孩子为空，建立前驱线索
			p->LTag = Thread;
			p->lchild = pre;
		}
		if (pre && !pre->rchild) {        // 前驱的右孩子为空，建立后继线索
			pre->RTag = Thread;
			pre->rchild = p;
		}
		pre = p;                          // 保持 pre 指向 p 的前驱
		InThreading(p->rchild);           // 线索化右子树
	}
}
```

## 03 带头结点的中序线索链表
为方便操作，增设一个**头结点**：
+ `head->lchild` 指向**根结点**，`head->rchild` 指向中序序列的**最后一个结点**。
+ 中序序列的**第一个结点**的 `lchild` 指向头结点，**最后一个结点**的 `rchild` 指向头结点。
+ 头结点的 `LTag = Link`，`RTag = Thread`。

```cpp
Status InOrderThreading(BiThrTree &Thrt, BiThrTree T) {
	// 中序遍历二叉树T，并将其中序线索化，Thrt指向头结点
	Thrt = (BiThrNode *)malloc(sizeof(BiThrNode));
	if (!Thrt) exit(OVERFLOW);
	Thrt->LTag = Link;
	Thrt->RTag = Thread;
	Thrt->rchild = Thrt;                  // 右指针回指
	if (!T) Thrt->lchild = Thrt;          // 空树
	else {
		Thrt->lchild = T;
		pre = Thrt;
		InThreading(T);                   // 中序线索化
		pre->RTag = Thread;               // 最后一个结点线索化
		pre->rchild = Thrt;
		Thrt->rchild = pre;
	}
	return OK;
}
```

>[!tip]
>头结点的作用类似于**循环链表**中的头结点，使第一个结点的前驱和最后一个结点的后继都有指向，遍历时不必对边界情况做特殊处理。

## 04 中序线索二叉树的遍历
**算法思路**：从根出发，先找到中序序列的**第一个结点**（最左下结点），然后反复找**后继**：
+ 若 `RTag == Thread`，`rchild` 即后继；
+ 否则，后继为右子树中序序列的第一个结点（右子树中最左下的结点）。

```cpp
Status InOrderTraverse_Thr(BiThrTree T, Status (*Visit)(TElemType e)) {
	// T指向头结点，头结点的lchild指向根结点
	p = T->lchild;                            // p指向根结点
	while (p != T) {                          // 空树或遍历结束时 p == T
		while (p->LTag == Link) p = p->lchild;  // 走到最左下结点
		if (!Visit(p->data)) return ERROR;
		while (p->RTag == Thread && p->rchild != T) {
			p = p->rchild;                    // 沿后继线索访问
			if (!Visit(p->data)) return ERROR;
		}
		p = p->rchild;                        // 转向右子树
	}
	return OK;
}
```

## 05 线索二叉树小结
| 操作 | 普通二叉链表 | 中序线索二叉树 |
| --- | --- | --- |
| 查找前驱/后继 | 需遍历，`O(n)` | 直接沿线索，`O(1)` |
| 遍历 | 递归或栈，`O(n)` 空间 | 不用栈，`O(1)` 空间 |
| 插入/删除 | 较简单 | 需维护线索，较复杂 |

>[!tip]
>线索二叉树适合**经常遍历、很少插入删除**的场景；若频繁修改，维护线索的代价较高。
>+ **中序线索**最常用，找前驱和后继都很方便。
>+ **先序线索**找后继方便，但找前驱仍需双亲信息。
>+ **后序线索**找前驱方便，但找后继仍需双亲信息。
