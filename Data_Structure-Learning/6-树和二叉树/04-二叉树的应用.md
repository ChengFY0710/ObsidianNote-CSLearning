## 01 创建二叉树
基于先序递归遍历算法
```cpp
Status CreateBiTree (BiTree &T) {
    //按先序次序输入二叉树中结点的值(一个字符)，空格字符表示空树，
    //构造二叉链表表示的二叉树T
    scanf("%c", &ch);
    if (ch==' ') T=NULL;
    else {
        if (!(T = (BiTNode *)malloc(sizeof(BiTNode))))
            exit (OVERFLOW);
        T->data = ch;            //生成根结点
        CreateBiTree(T->lchild); // 构造左子树，并设置T的左孩子指针
        CreateBiTree(T->rchild); // 构造右子树，并设置T的右孩子指针
    }
    return OK;
} // CreateBiTree
```

## 02 统计叶子结点数
**算法 1：分治法（返回叶子数）**
```cpp
int CountLeaf (BiTree T) {
    // 采用二叉链表存储结构
    // 通过递归遍历二叉树来找出叶子结点，并计数
    int nl, nr;
    if (!T) return 0;
    if (!T->lchild && !T->rchild) return 1;//叶子结点
    nl = CountLeaf(T->lchild);     //求左子树的叶子数
    nr = CountLeaf(T->rchild);     //求右子树的叶子数
    return nl+nr;
} // CountLeaf
```

**算法 2：引用参数计数**
```cpp
void CountLeaf (BiTree T, int &count) {
    // 采用二叉链表存储结构，增加一个用于“计数”的引用参数count
    // 通过递归遍历二叉树来找出叶子结点，并计数
    if ( T )
        if (!T->lchild && !T->rchild ) count++;  //对叶子结点计数
        else {
            CountLeaf(T->lchild, count);         //求左子树的叶子数
            CountLeaf(T->rchild, count);         //求右子树的叶子数
        }
} // CountLeaf
```

## 03 求二叉树的深度
**算法思路**：空树深度为 0；否则递归求左、右子树深度，取较大者加 1。
```cpp
int Depth (BiTree T) {
    // 采用二叉链表存储结构，返回二叉树T的深度
    if (!T) return 0;
    int m = Depth(T->lchild);      //求左子树的深度
    int n = Depth(T->rchild);      //求右子树的深度
    return (m > n ? m : n) + 1;
} // Depth
```

## 04 统计结点总数
**算法思路**：空树结点数为 0；否则为左子树结点数 + 右子树结点数 + 1。
```cpp
int NodeCount (BiTree T) {
    // 采用二叉链表存储结构，返回二叉树T的结点总数
    if (!T) return 0;
    return NodeCount(T->lchild) + NodeCount(T->rchild) + 1;
} // NodeCount
```

## 05 复制二叉树
**算法思路**：先创建根结点，再递归复制左、右子树。
```cpp
Status CopyBiTree (BiTree T, BiTree &NewT) {
    // 采用二叉链表存储结构，复制二叉树T到NewT
    if (!T) {
        NewT = NULL;
        return OK;
    }
    NewT = (BiTNode *)malloc(sizeof(BiTNode));
    if (!NewT) exit(OVERFLOW);
    NewT->data = T->data;                     //复制根结点
    CopyBiTree(T->lchild, NewT->lchild);      //复制左子树
    CopyBiTree(T->rchild, NewT->rchild);      //复制右子树
    return OK;
} // CopyBiTree
```

## 06 交换左右子树
**算法思路**：先交换根结点的左、右孩子指针，再递归交换左、右子树。
```cpp
void SwapLeftRight (BiTree &T) {
    // 采用二叉链表存储结构，交换二叉树T中每个结点的左、右子树
    if (!T) return;
    BiTree temp = T->lchild;      //交换左右孩子
    T->lchild = T->rchild;
    T->rchild = temp;
    SwapLeftRight(T->lchild);     //递归交换左子树
    SwapLeftRight(T->rchild);     //递归交换右子树
} // SwapLeftRight
```

## 07 销毁二叉树
**算法思路**：先递归销毁左、右子树，再释放根结点，防止内存泄漏。
```cpp
void DestroyBiTree (BiTree &T) {
    // 采用二叉链表存储结构，销毁二叉树T
    if (!T) return;
    DestroyBiTree(T->lchild);     //销毁左子树
    DestroyBiTree(T->rchild);     //销毁右子树
    free(T);                      //释放根结点
    T = NULL;
} // DestroyBiTree
```

>[!tip]
>二叉树的绝大多数操作都可以用**递归**实现：先处理根结点，再递归处理左、右子树。递归的**终止条件**通常是“树为空”。
