## 01 树的存储结构
### （1）双亲表示法
用一组**连续空间**存储树的结点，每个结点保存**数据**和**双亲的下标**。根结点的双亲下标为 `-1`。

```cpp
#define MAX_TREE_SIZE 100
typedef struct PTNode {
	TElemType data;
	int parent;               // 双亲位置域
} PTNode;
typedef struct {
	PTNode nodes[MAX_TREE_SIZE];
	int r, n;                 // 根的位置和结点数
} PTree;
```

+ **优点**：找**双亲**方便，时间复杂度为 `O(1)`。
+ **缺点**：找**孩子**需要遍历整个数组，时间复杂度为 `O(n)`。

### （2）孩子表示法
把每个结点的孩子结点排列起来，看成线性表，用**单链表**存储；n 个结点有 n 个孩子链表，另设一个头指针数组。

```cpp
typedef struct CTNode {
	int child;                // 孩子结点在表头数组中的下标
	struct CTNode *next;
} *ChildPtr;
typedef struct {
	TElemType data;
	ChildPtr firstchild;      // 孩子链表头指针
} CTBox;
typedef struct {
	CTBox nodes[MAX_TREE_SIZE];
	int n, r;                 // 结点数和根的位置
} CTree;
```

+ **优点**：找**孩子**方便。
+ **缺点**：找**双亲**不方便，可在 `CTBox` 中增加 `parent` 域，构成**双亲-孩子表示法**。

### （3）孩子兄弟表示法
每个结点设置两个指针：
+ `firstchild`：指向**第一个孩子**；
+ `nextsibling`：指向**下一个兄弟**。

```cpp
typedef struct CSNode {
	TElemType data;
	struct CSNode *firstchild, *nextsibling;
} CSNode, *CSTree;
```

>[!tip]
>孩子兄弟表示法又称**二叉链表表示法**，它把一棵**树**转换成了**二叉树**的形状，是树与二叉树转换的基础。其左指针相当于二叉树的**左孩子**，右指针相当于二叉树的**右孩子**。

## 02 树、森林与二叉树的转换
### （1）树转换为二叉树
+ **加线**：在所有**兄弟结点**之间加一条连线。
+ **抹线**：对每个结点，只保留它与**第一个孩子**之间的连线，删除与其他孩子之间的连线。
+ **旋转**：以根结点为轴心，将整棵树**顺时针旋转 45°**。

>[!tip]
>口诀：**左孩子、右兄弟**。

例如，树 `A` 有三个孩子 `B、C、D`：
```
        A                    A
      / | \                  /
     B  C  D       ->       B
                              \
                               C
                                \
                                 D
```

### （2）森林转换为二叉树
+ 先将森林中的每一棵树分别转换为二叉树。
+ 再把各棵二叉树的根结点用线连起来：后一棵树作为前一棵树根结点的**右孩子**。

```
森林:  T1   T2   T3         二叉树:  root(T1)
                                      \
                                       root(T2)
                                         \
                                          root(T3)
```

### （3）二叉树转换为树或森林
+ 若结点 x 是其双亲 y 的**左孩子**，则把 x 的**右孩子**、右孩子的右孩子……都与 y 连起来。
+ 删除所有双亲到**右孩子**结点的连线。
+ 整理（旋转）即可得到树或森林。

>[!note]
>+ 二叉树根结点**没有右子树**时，对应一棵**树**。
>+ 二叉树根结点**有右子树**时，对应一个**森林**。

## 03 树和森林的遍历
### （1）树的遍历
+ **先根遍历**：先访问根结点，再依次先根遍历根的每棵子树。
+ **后根遍历**：先依次后根遍历根的每棵子树，再访问根结点。

| 树的遍历 | 对应二叉树的遍历 |
| --- | --- |
| 先根遍历 | 先序遍历 |
| 后根遍历 | 中序遍历 |

>[!warning]
>树**没有中序遍历**。树的先根遍历序列与其对应二叉树的**先序序列**相同，后根遍历序列与其对应二叉树的**中序序列**相同。

### （2）森林的遍历
+ **先序遍历森林**：访问第一棵树的根结点，先序遍历第一棵树的子树森林，再先序遍历其余树构成的森林。
+ **中序遍历森林**：中序遍历第一棵树的子树森林，访问第一棵树的根结点，再中序遍历其余树构成的森林。

| 森林的遍历 | 对应二叉树的遍历 |
| --- | --- |
| 先序遍历 | 先序遍历 |
| 中序遍历 | 中序遍历 |

>[!tip]
>树和森林的遍历都可以借助其对应的**二叉树**来实现：先根遍历对应**先序**，后根/中序遍历对应**中序**。

## 04 树、森林与二叉树的关系
+ 一棵树可以唯一地转换成一棵**二叉树**，反之亦然。
+ 一个森林可以唯一地转换成一棵**二叉树**，反之亦然。
+ 转换后，二叉树中某结点的**左孩子**是原树中该结点的**第一个孩子**，**右孩子**是原树中该结点的**下一个兄弟**。
+ 这种转换只是**存储形式**的改变，不改变结点之间的**逻辑关系**。
