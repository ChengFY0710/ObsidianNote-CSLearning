## 01 树的递归定义
**树（tree）** 是n（n>=0）个节点的有限集。任意一棵非空树中：
+ 有且仅有一个特定的称为**根**的节点。
+ 当 n>1 时，其余节点可分为 m（m>1）个互不相交的有限集T1、T2、......、Tm，其中每个集合本身又是一棵树，并且成为**根的子树（SubTree）**。
![[引用文件/DataStructure-Learning/6-01-1.png|271]]
**基本概念**：
+ **结点（node）**：包含一个数据元素及若干指向其子树的分支。
+ **结点的度（degree）**：结点拥有的**子树数**。
+ **叶子（leaf）/终端结点**：度为 0 的结点。
+ **分支结点/非终端结点**：度不为 0 的结点。
+ **内部结点**：除根结点之外的分支结点。
+ **孩子（child）、双亲（parent）**：结点的**子树的根**，称为该结点的孩子；相应地，该结点称为孩子的双亲。
+ **兄弟（sibling）**；同一双亲的孩子。
+ **祖先**：从根到该结点所经分支上的所有结点。
+ **子孙**：以该结点为根的子树的任意结点。
+ **堂兄弟**：双亲在同一层，但双亲不相同的结点。
+ **结点的层次（level）**：从根结点算起，根为第一层，它的孩子为第二层。
+ **树的深度（depth）/高度**：树中结点的最大层次数。
+ **有序树、无序树**：如果树中结点的各子树看成**从左至右**是**有次序**的（即不能互换），则称该树为有序树，否则称为无序树。
+ **森林（forest）**：m(m>=0)棵互不相交的树的集合。每个结点的子树的集合，称为该结点的子树森林。

## 02 树和森林的互递归定义
任何一棵树是一个**二元组Tree=(root, F)**，其中root是数据元素，称为树的根结点，F时m(m>=0)棵子树的森林，F=(T1，T2，...，Tm)，其中Ti=(ri, Fi)称作根root的第 i 棵子树；

## 04 树的性质
设树的结点数为 n，边的总数为 e：
+ **结点数 = 所有结点的度数之和 + 1**，即 `n = Σ(结点的度) + 1`。
+ **边数 = 结点数 - 1**，即 `e = n - 1`，也等于所有结点的度数之和。
+ 度为 m 的树中，第 i 层至多有 `m^(i-1)` 个结点（`i >= 1`）。
+ 高度为 h 的 m 叉树至多有 `(m^h - 1) / (m - 1)` 个结点。
+ 具有 n 个结点的 m 叉树的最小高度为 `⌈log_m(n(m-1)+1)⌉`。
+ 若树中有 `n_i` 个度为 i 的结点，则：
  + `n = n_0 + n_1 + ... + n_m`
  + `n = 1 + n_1 + 2n_2 + ... + m n_m`

>[!tip]
>树中**结点总数**比**边的总数**多 1；所有结点的度数之和等于**分支数**，也等于**边数**。
