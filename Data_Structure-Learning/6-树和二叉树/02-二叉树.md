## 01 二叉树的定义
+ **二叉树（Binary tree）**：是 n(n>=0) 个结点的有限集合。
+ **空树**：n=0 时，即没有任何结点。
+ **树的根结点（Root）**：有且只有一个特殊的结点。
+ **左、右子树**：若 n>1  时，其余的结点被分成为**两个互不相交的子集T1、T2**，分别称为**左、右子树**，并且左、右子树又都是**二叉树**或**空树**。
![[引用文件/DataStructure-Learning/Pasted image 20261013191904.png|274]]
### （1）满二叉树
**满二叉树（Full Binary Tree）**：深度为 k 且含有 `2^k - 1` 个结点的二叉树。它的每一层结点数都达到最大值，所有叶子结点都在最底层。
![[引用文件/DataStructure-Learning/Pasted image 20261013195340.png|381]]

### （2）完全二叉树
**完全二叉树（Complete Binary Tree）**：深度为 k、有 n 个结点的二叉树，当且仅当其每个结点都与深度为 k 的满二叉树中编号为 `1 ~ n` 的结点**一一对应**。
![[引用文件/DataStructure-Learning/Pasted image 20261013195623.png|377]]
+ 叶子结点只可能出现在**最下面两层**。
+ 最下面一层的叶子结点依次集中在**左侧**。
+ 若某个结点只有**左孩子**，则该左孩子一定是**叶子结点**。
+ 具有 n 个结点的完全二叉树的高度为 `⌊log2 n⌋ + 1`（也等于 `⌈log2(n+1)⌉`）。
![[引用文件/DataStructure-Learning/Pasted image 20261013201635.png|463]]

>[!tip]
>**满二叉树一定是完全二叉树**，但完全二叉树不一定是满二叉树。

## 02 二叉树的性质
+ **性质 1**：二叉树第 i 层至多有 `2^(i-1)` 个结点（`i >= 1`）。
+ **性质 2**：深度为 k 的二叉树至多有 `2^k - 1` 个结点（`k >= 1`）。
+ **性质 3**：对任何一棵二叉树，若叶子结点数为 `n0`，度为 2 的结点数为 `n2`，则 `n0 = n2 + 1`。
+ **性质 4**：具有 n 个结点的完全二叉树的高度为 `⌊log2 n⌋ + 1`。
+ **性质 5**：对==🟢**完全二叉树**==按层从上到下、从左到右从 1 开始编号：
  + 结点 i 的双亲为 `⌊i/2⌋`（`i > 1`）；
  + 左孩子为 `2i`（`2i <= n`），右孩子为 `2i+1`（`2i+1 <= n`）；
  + 若 `2i > n`，则结点 i 无左孩子，为**叶子结点**。
  + 若数组下标从 0 开始存储，则双亲为 `⌊(i-1)/2⌋`，左孩子为 `2i+1`，右孩子为 `2i+2`。

>[!note]
>**二叉树不是树的特殊情况**：二叉树可以为空，且左、右子树严格有序；而树至少有一个根结点，子树之间没有左右次序（有序树除外）。**度为 2 的树**与**二叉树**也不等价。

>[!tip]
>性质 3 的推导：设结点总数为 n，则 `n = n0 + n1 + n2`；又边数 `n - 1 = n1 + 2n2`，联立可得 `n0 = n2 + 1`。

## 03 二叉树的存储结构
### （1）顺序存储

```cpp
#define MAX_TREE_SIZE 100
typedef TElemType SqBiTree[MAX_TREE_SIZE];
SqBiTree bt;
```

>[!tip]
>约定：用一组**连续的**存储单元**依次自上而下、从左到右**存储完全二叉树上的结点元素。如图：
>![[引用文件/DataStructure-Learning/Pasted image 20261013202925.png]]

>[!warning]
>二叉树顺序存储的缺点：
>+ 在最坏的情况下，一个深度为k，且只有k个结点的右**单支树**却需要 2^k - 1 个结点的存储空间。
>![[引用文件/DataStructure-Learning/Pasted image 20261013203435.png]]
>+ 插入或删除一颗子树时，顺序存储方式实现起来不是很方便。

### （2）链式存储
**二叉链表**：结点至少包含 3个域：**数据域、左指针域、右指针域**。

|Lchild|data|Rchild|
|---|---|---|

**三叉链表**：在二叉链表节点上再**增加 1 个 指向双亲结点的指针域**。

| Lchild | data | ==🔴parent== | Rchild |
| ------ | ---- | ------------ | ------ |

二叉链表的存储表示：
```cpp
typedef struct BiTNode {
	TElemType data;
	struct BiTNode *Lchild, *Rchild;
} BiTNode, *BiTree;
```

![[引用文件/DataStructure-Learning/Pasted image 20261013204524.png]]
三叉链表的存储表示
```cpp
typedef struct BiTNode {
	TElemType data;
	struct BiTNode *Lchild, *Rchild, *parent;
} BiTNode, *BiTree;
```
