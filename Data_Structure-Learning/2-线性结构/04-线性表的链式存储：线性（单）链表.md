## 00 线性表的链式存储分类
**按连接方式分类**：
+ 线性链表 / 单链表
+ 循环链表
+ 双向链表
**按实现方式分类**：
+ 动态链表
+ 静态链表
## 01 定义
链表中的每个节点只包含**一个**用来指示**直接后继**的指针域。
+ **头指针**：指链表中第一个节点的存储位置。
+ **头节点**：在表的第一个节点之前附设一个节点，其next域指向第一个元素节点，其data域可以不存储任何信息，也可用于存储表长等附加信息。

## 02 单链表的相关操作
### （1）单链表的查找-按位序
**算法思路**：
+ **初始化**：p指向第一个节点，j为计数器。
+ **循环查找**：直到 j == i 或 p越界。
+ **结束查找**：保存找到的位置。
```cpp
Status GetElem_L(LinkList L, int i, ElemType &e){
	p = L->next; j=1; 
	while(p && j<i){
		p = p->next;
		j++;
	}
	if(!p || j>i) return ERROR;
	e = p->data;
	return OK;
}
```
### （2）单链表的插入
**算法思路**：
+ **找到对应的位置**：单链表的按位序查找。
+ **生成新节点**：为即将插入的元素新建内存。
+ **调整链表关系**：实现插入链表。

```cpp
Status ListInsert_L(LinkList L, int i, ElemType e){
	p = L; j=0;
	while(p && j<i-1){p=p->next; ++j;}
	if(!p||j>i-1) return ERROR;
	s = (LinkList*)malloc(sizeof(LNode));
	s->data = e;
	s->next = p->next;
	p->next = s;
	return OK;
}
```
### （3）单链表的删除
**算法思路**：
+ **找到删除位置**：单链表的按序查找。
+ **调整链表关系**：实现链表节点的删除。
+ **释放空间**：free()

```cpp
Status ListDelete_L(LinkList &L, int i, ElemType &e){
	p = L; j=0;
	while(p&& j<i-1){p=p->next; ++j;}
	if(!p||j>i-1) return ERROR;
	q = p->next; p->next = q->next;
	e = q->data;
	free(q);
	return OK;
}
```
### （4）单链表的创建
**算法思路**：
+ **创建头节点**：先创建一个带头节点的单链表。
+ **循环创建单链表**：先生成新节点，给新节点赋值，再将该节点插入单链表中。
#### 头插法
```cpp
void CreateList_L(LinnkList &L, int n){
	L = (LinkList*)malloc(sizeof(LNode));
	L->next = NULL;
	for(i = n; i>0; --i){
		p=(LinkList*)malloc(sizeof(LNode));
		scanf(&p->data);
		p->next = L->next;
		L->next = p;
	}
}
```

>[!tip] 头插法
>采用头插法创建的单链表，插入顺序与单链表中的**顺序相反**。
>头插法核心：p->next = L->next; L->next = p;
>两句顺序**不可变！！**

#### 尾插法
**算法思路**：
+ **创建头节点**：先创建一个头节点L。
+ **循环创建单链表**：先生成新节点，给新节点赋值，调整链表关系。
```cpp
void CreateList_L(LinnkList &L, int n){
	L = (LinkList*)malloc(sizeof(LNode));
	L->next = NULL;
	r = L;
	for(i = 0; i<n; i++){
		p=(LinkList*)malloc(sizeof(LNode));
		scanf(&p->data);
		r->next = p;
		r = p;
	}
}
```

### （5）归并两个有序单链表
**算法思路**：
+ **初始化**：两个指针指向La，Lb开头，新建Lc，获取La，Lb长度。
+ **循环比较归并操作**：循环比较，移动指针。
+ **扫尾**：将剩余的数据插入Lc末尾。

```cpp
void MergeList_L(LinkList &La, LinkList &Lb, LinkList &Lc){
	pa = La->next; pb = Lb->next;
	Lc = pc = La;
	while(pa && pb){
		if(pa->date <= pb->date){
			pc->next = pa; pc = pa; pa = pa->next;
		}
		else{pc->next = pb; pc = pb; pb = pb->next;}
	}
	pc->next = pa ? pa : pb;
	free(Lb);
}
```
