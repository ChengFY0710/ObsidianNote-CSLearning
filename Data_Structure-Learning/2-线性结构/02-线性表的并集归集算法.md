## 01 并集算法
假设有两个线性表 LA，LB，现要求一个新的集合C，C为LA与LB的并集。
**算法思路**：
+ **初始化**：求LA与LB的表长，La_len，Lb_len。
+ **合并**：遍历LB，若LB的第 i 个元素在LA中不存在，则将其插入LA的末尾。
```cpp
void Union(List &La, List Lb){
	La_len = Listlength(La);
	lb_len = ListLength(Lb);
	for(i=1; i<=Lb_len; i++){
		GetElem(Lb, i, e);
		if(!LocateElem(La, e, equal())){
			ListInsert(La, ++La_len, e);
		}
	}
}
```

## 02 归并有序线性表算法
已知La与Lb数据元素按值非递减有序排列，现要求将La与Lb归并为一个新的线性表Lc，且Lc中的元素仍按值非递减有序排列。
**算法思路**：
+ **初始化**：构建空表Lc，设置三个辅助指针i, j, k，分别指向La，Lb第一个元素，以及Lc的**第一个元素**。
+ **同时遍历La，Lb**：直到其中一个线性表的元素全部处理完毕。即：比较la，lb的第i，j个元素，谁小就插入Lc末尾，对应的指针后移，另一个不动。
+ **扫尾**：遍历后将剩余元素插入Lc的末尾。

```cpp
void MergeList(List La, List Lb, List &Lc){
	InitList(Lc);
	i = j = 1; k = 0;
	La_len = ListLength(La); Lb_len = ListLength(Lb);
	while(i<=La_len && j<=Lb_len){
		GetElem(La, i, ai); GetElem(Lb, j, bj);
		if(ai <= bj){ListInsert(Lc, ++k, ai); ++i}
		else{ListInsert(Lc, ++k, bj); ++j;}
	}
	while(i<=La_len){GetElem(La, i++, ai); ListInsert(Lc, ++k, ai);}
	while(j<=Lb_len){GetElem(Lb, j++, bj); ListInsert(Lc, ++k, bj);}
}
```
