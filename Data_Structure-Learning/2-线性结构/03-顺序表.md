## 01 定义
采用**顺序存储结构**的线性表，即把线性表的节点按逻辑顺序依次存放在一组地址**连续的**存储单元里。
>[!note]
>线性表的顺序存储结构是一种**随机存取**的存储结构，即存取数据所需**时间**与存储**位置无关**。
## 02 基本操作

### （2）顺序表的插入
**算法思路**：
+ **检查参数**：若插入位置 i 不合法，则算法异常终止
+ **检查空间**：若线性表空间不足，则分配新空间，如果分配成功，则修改线性表的容量，否则算法异常终止。
+ **插入元素**：将插入位置 i 以及其后的元素全部后移一个位置，将元素e插入位置i，表长增加 1。

```cpp
Status ListInsert_Sq(SqList &L, int i, ElemType e) {
    if (i < 1 || i > L.length + 1) 
        return ERROR;        // 插入位置不合法

    if (L.length >= L.listsize) {   // 当前存储空间已满，增加分配
        newbase = (ElemType *) realloc(L.elem,
            (L.listsize + LISTINCREMENT) * sizeof(ElemType));
        if (!newbase) 
            exit(OVERFLOW);        // 存储分配失败
        L.elem = newbase;
        L.listsize += LISTINCREMENT; // 新基址，增加容量
    }

    q = &(L.elem[i - 1]);        // q 指示插入位置
    for (p = &(L.elem[L.length - 1]); p >= q; --p)
        *(p + 1) = *p;           // 插入位置及之后的元素右移
    
    *q = e;
    ++L.length;                  // 插入e，表长增1
    return OK;
} // ListInsert_Sq
```

### （3）顺序表的删除
**算法思路**：
+ **检查参数**：若删除位置超出范围，则算法异常终止。
+ **删除元素**：将删除元素的值赋值给e，将被删除元素之后的元素全部前移，表长减1。
```cpp
Status ListDelete_Sq(SqList &L, int i, ElemType &e){
	if(i<1 || i>L.length) return ERROR;
	p = &(L.elem[i-1]);
	e = *p;
	q = L.elem+L.length-1;
	for(++p; p<=q; ++p)
		*(p-1) = *p; // 被删除元素之后元素左移
	--L.length;
	return OK;
}
```
