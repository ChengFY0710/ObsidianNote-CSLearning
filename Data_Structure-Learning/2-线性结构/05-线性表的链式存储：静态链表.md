## 01 定义
用**一维数组**来描述的链表。
```cpp
#define MAXSIZE 1000
typedef struct{
	ElemType date;
	int cur;
}component, SLinkList[MAXSIZE];

Status InitList(SLinnkList space){
	int i;
	for(i=0; i<MAXSIZE-1; i++){
		space[i].cur = i+1;
	}
	space[MAXSIZE-1].cur = 0;
	return OK;
}
```
+ **游标（指示器）cur**：指示后继结点**在数组中**的**相对**位置。

## 02 基本操作
### （1）按内容查找
```cpp
int LocateElem_SL(SLinkList L, int s, ElemType e){
	i = L[s].cur;
	while(i && L[i].data != e)
		i = L[i].cur;
	return i;
}
```
在带头结点的静态单链表L（s为头指针）中查找第一个值为e的元素，若找到，返回它在L中的**下标**，否则返回0。
### （2）创建静态链表
```cpp
void InitSpace_SL(SLinkList &space){
	for(i=0; i<MAXSIZE-1; ++i){
		space[i].cur=i+1;
	}
	space[MAXSIZE-1].cur=0;
}
```
### （3）空间分配
```cpp
int Malloc_SSL(SLinkList space){
	int i = space[0].cur;
	
	if(space[0].cur)
		space[0].cur = space[i].cur;
		
	return i;
}
```
