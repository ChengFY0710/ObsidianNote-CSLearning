## 01 定义
用**一维数组**来描述的链表。
```cpp
#define MAXSIZE 1000
typedef struct{
	ElemType date;
	int cur;
}component, SLinkList[MAXSIZE];

Status InitList(SLinnkList space){
	int i;
	for(i=0; i<MAXSIZE-1; i++){
		space[i].cur = i+1;
	}
	space[MAXSIZE-1].cur = 0;
	return OK;
}
```
+ **游标（指示器）cur**：指示后继结点**在数组中**的**相对**位置。

## 02 基本操作
### （1）按内容查找
```cpp
int LocateElem_SL(SLinkList L, int s, ElemType e){
	i = L[s].cur;
	while(i && L[i].data != e)
		i = L[i].cur;
	return i;
}
```
在带头结点的静态单链表L（s为头指针）中查找第一个值为e的元素，若找到，返回它在L中的**下标**，否则返回0。
### （2）创建静态链表
```cpp
void InitSpace_SL(SLinkList &space){
	for(i=0; i<MAXSIZE-1; ++i){
		space[i].cur=i+1;
	}
	space[MAXSIZE-1].cur=0;
}
```
### （3）空间分配
```cpp
int Malloc_SSL(SLinkList space){
	int i = space[0].cur;
	
	if(space[0].cur)
		space[0].cur = space[i].cur;
		
	return i;
}
```

### （4）静态链表插入
```cpp
Status ListInsert(StaticLinkList L, int i, ElemType e){
	int j, k, l;
	k = MAXSIZE - 1;
	if(i<1 || i>ListLength(L) + 1)
		return ERROR;
	j = Malloc_SSL(L);
	if(j){
		L[j].data = e;
		for(l=1; l<= i-1; l++){
			k = L[k].cur;
		}
		L[j].cur = L[k].cur;
		L[k].cur = j;
		return OK;
	}
	return ERROR;
}
```

### （5）静态链表删除节点
```cpp
Status ListDelete(SLinkList L, int i){
	int j, k;
	if(i < 1 || i > ListLength(L))
		return ERROR;
	k = MAXSIZE - 1;
	for(j=1; j<=i-1; j++)
	 k = L[k].cur;
	j = L[k].cur;
	L[k].cur = L[j].cur;
	Free_SSL(L, j);
	return OK;
}
```
```cpp
void Free_SSL(SLinkList space, int k){
	space[k].cur = space[0].cur;
	space[0].cur = k;
}
```

## 04 静态链表的优缺点
优点：在插入和删除操作时，只需要修改游标，不需要移动元素，从而改进了在顺序存储结构中插入和删除操作需要移动大量元素的缺点。
缺点：没有解决连续存储分配带来的表长难以确定的问题，失去了顺序存储结构随机存取的特性。
