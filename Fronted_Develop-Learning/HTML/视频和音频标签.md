## 01 video 视频标签
写法：
```html
<video src="yu7.mp4" controls autoplay mute loop poster="yu7.png"></video>
```
兼容性写法：
```html
<video controls autoplay mute loop poster="yu7.png">
  <source src="./yu7.mp4" type="video/mp4">
  <source src="./yu7.webm" type="video/webm">
  <source src="./yu7.ogg" type="video/ogg">
  <p>你的浏览器不支持video标签</p>
 </video>
```

## 02 audio 音频标签
写法：
```html
<audio src="yu7.mp3" controls autoplay mute loop></audio>
```
兼容性写法：
```html
<audio controls autoplay mute loop>
  <source src="./yu7.mp3" type="audio/mp3">
  <P>Your browser doesn't support audio. Please upgrade your browser.</p>
</audio>
```
